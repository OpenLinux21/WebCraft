## 概述

用正确的标记和精确的盒子搭出的页面，依然可能显得业余——因为人们所说的大部分"设计"，其实就是两个决定：选哪些颜色，用哪种字体。本课把这两件事一次讲清，它们值得这三十分钟。

颜色和字体共享一个机械的内核和一层艺术的表皮。机械的部分很小：四种颜色写法、一个字体属性、三个字号单位。艺术的部分是判断力：对比度要尊重读者的眼睛，间距要让文字呼吸，克制地让一页只用一两种字体、一个强调色。

排版还是穿着设计外衣的无障碍议题。能优雅降级的字体栈、尊重用户设置的 `rem` 字号、给行间留出空隙的行高——这些选择决定了页面究竟"能不能读"，对低视力读者、阳光下的手机、200% 缩放的使用者都是如此。

练习会给一个素面引言页配齐整套主题：纸感背景、衬线字体栈、舒适的行宽和一个真正"会喊"的标题。这是 CSS 模块的最后一个练习，它把第 4、5 课的内容一并收拢。

## 颜色的四种写法

CSS 接受四种颜色语法，每种都有自己擅长的场景：

| 语法    | 示例                 | 适用场景                  |
| ------- | -------------------- | ------------------------- |
| 命名色  | `darkblue`           | 快速演示；共约 148 个名字 |
| hex     | `#1e3a8a`            | 从设计工具复制来的值      |
| `rgb()` | `rgb(30, 58, 138)`   | 同样的事，用十进制写      |
| `hsl()` | `hsl(224, 76%, 33%)` | 想要*调整*的颜色          |

hex 和 `rgb` 描述同一个事实——红绿蓝各占多少；`hsl` 则按人们思考颜色的方式来描述：0 到 360 的色相环上的色相、以百分比计的饱和度、以百分比计的亮度。想要深一点的版本？保住色相、压低亮度。这就是设计师在搭建调色板时偏爱 `hsl` 的原因：

```css
body {
  color: darkslategray; /* a named color */
}

h1 {
  color: #1e3a8a; /* hex: red green blue */
}

blockquote {
  color: hsl(224, 76%, 33%); /* hue, saturation, lightness */
}
```

每种语法都能再接第四个值表示透明度，让颜色可以"半途而废"：

```css
.overlay {
  color: rgba(30, 58, 138, 0.7); /* the last number is opacity */
}
```

挑颜色时提醒一句：无论选什么，文字都必须在背景上保持可读。低对比的配色在作品集里显得潇洒，在公交车上没法读。

> **动手试一试：** 在内置编辑器里先用命名色给 `h1` 上色，再改写成 hex，再改写成 `hsl`。每步都预览——三种语法，同一个颜色。

## 字体族与回退字体栈

`font-family` 属性从来不只写一个字体。它写的是一*栈*：一份从左到右遍历的愿望清单，浏览器用其中第一个真正可用的字体：

```css
body {
  font-family: Georgia, 'Times New Roman', serif;
}
```

两个细节决定字体栈的成败。其一，带空格的名字要加引号——`"Times New Roman"`。其二，字体栈必须以*通用字体族*收尾，它是任何机器上都有货的安全网：`serif` 像书籍报刊，`sans-serif` 像屏幕和界面，`monospace` 像代码。

| 通用字体族   | 外观           | 天然阵地         |
| ------------ | -------------- | ---------------- |
| `serif`      | 笔画末端有脚   | 长文阅读         |
| `sans-serif` | 无脚、笔画均匀 | 界面、按钮       |
| `monospace`  | 每个字符等宽   | 代码、数据       |
| `system-ui`  | 设备自带字体   | 类应用的现代页面 |

预览沙盒没有网络访问权限——这反而是很好的训练：这里加载不了花哨的网络字体，你只能学习搭建离线可用的字体栈，而这本来就是真实网站上回退方案该有的样子。Georgia 加 `serif` 就是一份完整、诚实的字体栈。

> **动手试一试：** 在编辑器里给 `body` 设一个字体栈并预览。然后把 `monospace` 挪到栈首，看整页变成终端风。

## 字号单位：px、em 与 rem

三个单位争夺你的字号，差异比看上去更重要：

| 单位  | 含义                 | 用途                     |
| ----- | -------------------- | ------------------------ |
| `px`  | 固定像素             | 边框、发丝线、精确的图标 |
| `em`  | 相对元素*自身*的字号 | 随文字缩放的内边距       |
| `rem` | 相对*根*字号         | 字号体系本身             |

`em` 的坑在于它像滚雪球：元素套元素套元素，比例一路相乘。所以字号体系偏爱 `rem`——每个 `rem` 都指向根字号（通常 16px），不管元素埋得多深：

```css
body {
  font-size: 16px;
}

h1 {
  font-size: 2rem; /* 32px: 2 x 16 */
}

h2 {
  font-size: 1.25rem; /* 20px */
}

small {
  font-size: 0.875rem; /* 14px */
}
```

整页用 `rem` 计量还有一个安静的无障碍红利：把浏览器默认字号调大的读者，会让你的整个页面等比放大，标题和小字一起放大。写死的像素字号则完全无视这种偏好。

一套能用的字号体系其实用不了几档——正文、小字、两级标题——每档就是某个 `rem` 倍数。别忍不住给每个元素都发明一个新字号。

> **动手试一试：** 在编辑器里把 `body` 设为 `font-size: 16px`，给 `h1` 设 `font-size: 2rem`。再把基准改成 `20px` 并预览：标题跟着变了，因为 `rem` 以根为准。

## 行高、字重与强调

文字是一行一行读的，`line-height` 决定阅读是轻松还是憋闷。用无单位的数字来设——它是字号的倍数：

```css
body {
  line-height: 1.6; /* roomy: body text wants 1.5 to 1.7 */
}

h1 {
  line-height: 1.2; /* headings want to hug their own size */
}
```

本节的其余部分是一盒小小的文字化妆工具，每个属性只做一件事：

```css
h1 {
  font-weight: 800; /* 400 normal, 700 bold, up to 900 */
  text-transform: uppercase;
  letter-spacing: 0.08em;
}

a {
  text-decoration: none; /* or underline, the default */
}

blockquote footer {
  font-style: italic;
}
```

`font-weight` 从 100 到 900、每 100 一档；`font-style` 倾斜；`text-decoration` 加下划线（或去掉链接的下划线）；`text-transform` 改变大小写却不碰底层文字；`letter-spacing` 往词里加空气，用在简短的大写标题上最出彩。

现在就采纳一个鲜明的观点：永远不要为了装出大写标题而把大写字母敲进 HTML。句子照常写，化妆交给 `text-transform`——这样屏幕阅读器读到的是"Words to keep"这个句子，而不是一场拼写比赛。

> **动手试一试：** 在编辑器里给 `body` 设 `line-height: 1.6`，给 `h1` 设 `text-transform: uppercase` 加 `letter-spacing: 0.1em`。和默认效果对比——一个新字体都没加，页面就多了分量。

## 搭建一套小小的排版体系

上面的一切组装起来，就是六行声明，给页面一个连贯的声音：

```css
body {
  font-family: Georgia, 'Times New Roman', serif;
  font-size: 16px;
  line-height: 1.6;
  color: hsl(215, 25%, 20%);
  background-color: hsl(40, 40%, 96%);
}

h1,
h2 {
  line-height: 1.2;
}

blockquote {
  font-size: 1.25rem;
}
```

把这条规则读出声：衬线字体栈，暖纸面上的冷静近黑色，宽松的行高，更紧凑的标题，稍大一号的引言。五个决定，一套体系——而且因为它们都住在 `body` 上，第 4 课的继承会免费把它们送到每个元素手里。

最后一种配料是行宽——一行文字跑多远——而你已经拥有它：第 5 课的 `max-width` 把行控制在 45 到 75 个字符的舒适区间。排版和盒模型恰好在这一点相遇。

真实的设计系统会再加一套间距刻度和第二种标题字体，但这套规则的骨架就是它们的骨架。从 body 出发，用 `rem` 分级，让继承负责配送。

> **动手试一试：** 在编辑器里敲出上面的 body 规则并预览。然后把 `background-color` 里的色相从 40 改成 120，看页面自己换装——一个数字，全新的情绪。

## 练习思路：给引言页配主题

起始页是一页"没有声音"的文字：一个标题、一条带署名的 blockquote、一段说明。标记已完成，CSS 里的 TODO 注释圈出了主题的轮廓。

按 TODO 标记的顺序推进：

1. 在 `body` 上设置以通用字体族收尾的 `font-family` 字体栈——引言页适合衬线栈。
2. 在 `body` 上用 `hsl()` 选出纸感的 `background-color` 和深色的文字 `color`。
3. 把 `blockquote` 设为 `1.25rem`，配 `line-height: 1.6`。
4. 让 `h1` 变成大写并加上 `letter-spacing`。
5. 弱化 `blockquote footer`：`0.875rem` 加更暗的颜色。

第 1、2 步给页面声音，第 3 到 5 步建立层级：引言最大，标题靠字距而不是字号来强调，署名保持安静。如果两个 `hsl` 颜色感觉不对，先调亮度——纸是高亮度，墨是低亮度。

写完之后，以读者身份预览：能否一眼区分引言和评论？能否一口气读完不丢行？这些才是那些数字真正要服务的考试。

> **提示：** 像设计师那样"偷师"：给背景家族选一个色相、给强调色选一个，其余全部通过调亮度派生。整个网站靠两个 `hsl` 起点就能跑起来。

## 常见错误

### 1. 低对比度的文字

白底浅灰看起来精致，读起来受罪；正文要保持够暗。

错误写法：

```css
body {
  color: #cccccc;
} /* barely visible on white */
```

正确写法：

```css
body {
  color: hsl(215, 15%, 25%);
}
```

### 2. 行高太紧

低于 1.4 左右，正文的行就会在视觉上黏连，眼睛找不到回行的地方。

错误写法：

```css
body {
  line-height: 1;
}
```

正确写法：

```css
body {
  line-height: 1.6;
}
```

### 3. 字体名不加引号

多词字体名不加引号会破坏整条声明，浏览器直接跳到下一个字体。

错误写法：

```css
body {
  font-family:
    Times New Roman,
    serif;
}
```

正确写法：

```css
body {
  font-family: 'Times New Roman', serif;
}
```

### 4. 到处写死像素字号

纯像素字号无视读者浏览器的设置；`rem` 字号会随偏好缩放。

错误写法：

```css
h1 {
  font-size: 48px;
}
```

正确写法：

```css
h1 {
  font-size: 3rem;
}
```

### 5. 字体族太多

每多一种字体就多花一份注意力；标题一种、正文一种已经很奢侈。

错误写法：

```css
body {
  font-family: Georgia, Verdana, 'Comic Sans MS', Impact, serif;
}
```

正确写法：

```css
body {
  font-family: Georgia, serif;
}
h1 {
  font-family: Verdana, sans-serif;
}
```

### 6. 把大写字母敲进 HTML

屏幕阅读器可能把全大写文本逐字拼读或大声喊出；大小写属于 CSS，不属于文字本身。

错误写法：

```html
<h1>WORDS TO KEEP</h1>
```

正确写法：

```html
<h1>Words to keep</h1>
```

```css
h1 {
  text-transform: uppercase;
}
```

> **提示：** 排版错误在代码里隐形，在页面上一目了然。每次配完主题，把手伸直了读一遍页面：你眯眼了，别人也会。

## 小结

- 颜色有命名、hex、`rgb()` 和 `hsl()` 四种写法；`hsl` 是用来调的，第四个值控制透明度。
- `font-family` 接受一个字体栈：带引号的名字，再加一个通用字体族当安全网。
- `px` 固定，`em` 会连乘，`rem` 以根为准——字号体系属于 `rem`。
- 无单位的 `line-height` 决定可读性；正文要 1.5 到 1.7，标题更紧。
- `font-weight`、`font-style`、`text-decoration`、`text-transform` 和 `letter-spacing` 只化妆、不改字。
- 一套主题就是 body 上的几条声明，靠继承配送到全页——你已经为引言页配好了一套。
